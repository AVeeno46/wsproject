# 검색어(유사어) 사전 — 서버 연동 여부 (Client · Server)

> 이 기능은 이 프로젝트에서 유일하게 **서버 계약이 전혀 없는** 기능이다.
> 지금은 [synonymModel.js](../src/models/synonymModel.js)가 전부 이 브라우저의
> localStorage에만 읽고 쓴다(`synonymDictionary:{userId}` 키) — 서버로 나가는
> 요청이 하나도 없다.

**적용 범위**: 없음(아직 서버 연동 자체가 결정 안 됨) — 이 문서는 확인이
필요한 질문만 정리해둔 상태.

## 1. 지금 실제로 되는 것

- "검색어 관리" 화면에서 단어-동의어 매핑을 추가/수정/삭제/저장 가능
- 새로고침해도 유지됨(로컬 저장이라 이 브라우저·이 계정에서만)

## 2. 안 되는 것 (중요)

- **다른 기기/브라우저와 동기화 안 됨** — 로컬 저장이라 당연한 한계
- **실제 AI 검색(RAG)에 전혀 반영 안 됨** — 이 사전에 "이수신청서 = 과정
  신청서"라고 등록해놔도, 실제로 "과정 신청서"로 검색했을 때 "이수신청서"
  문서가 같이 검색되는 로직 자체가 없음. 지금은 편집만 되는 화면일 뿐, 검색
  파이프라인과 아예 연결이 안 되어 있음

## 3. 미정 / 확인 필요

- [ ] **이 기능을 서버와 연동할 계획이 있는지 자체가 미확정** — 지금까지
      "나중에" 정도로만 언급됐지 실제로 진행하기로 결정된 적 없음
- [ ] 연동한다면: 사전을 서버에 저장해서 여러 기기에서 동기화할지
- [ ] 연동한다면: 실제 검색 시 이 사전을 어떻게 활용할지(쿼리 확장? 인덱싱
      시 동의어 태깅?) — RAG 파이프라인 쪽 설계가 필요한 부분이라 서버/RAG
      팀 판단이 필요함

## 4. 클라이언트 상태

**이미 준비된 것**
- CRUD 화면 자체는 완성([SynonymDictionaryPage.jsx](../src/features/dashboard/SynonymDictionaryPage.jsx),
  [synonymViewModel.js](../src/viewmodels/synonymViewModel.js))
- 계정별 localStorage 분리 완료

**아직 안 한 것**
- 서버 API 자체(엔드포인트 없음)
- 검색 파이프라인과의 연결(이게 없으면 이 화면은 사실상 "동의어 메모장"일 뿐)
